# zeropress.dev

This repository hosts [zeropress.dev](https://zeropress.dev/), the public
technical documentation site for ZeroPress contracts, theme authoring, CLI
packages, and renderer behavior.

The site is built and deployed with
[zeropress-app/zeropress-build-pages](https://github.com/zeropress-app/zeropress-build-pages).
It is maintained as a dogfooding site for the Build Pages workflow and the
current ZeroPress documentation theme.
