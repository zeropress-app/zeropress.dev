# ZeroPress Documentation

ZeroPress is open-source software for creating and publishing static websites.
Keep writing in WordPress with ZeroPress Static, use Studio, or work in Markdown.
Publish your content as files you can build and host independently.

## Choose How To Publish

| Start with | Use it to | Starter repository |
| --- | --- | --- |
| [WordPress](getting-started/index.md#publish-from-wordpress) | Keep your editor and publish a static site with ZeroPress Static | [WXR Starter](https://github.com/zeropress-app/zeropress-starter-wxr) |
| [Studio](getting-started/index.md#publish-with-studio) | Write, manage media, and publish from your browser | [Studio Starter](https://github.com/zeropress-app/zeropress-starter-studio) |
| [Markdown](getting-started/index.md#publish-markdown) | Maintain a documentation site in Git | [Markdown Starter](https://github.com/zeropress-app/zeropress-starter-markdown) |

Follow [Getting Started](getting-started/index.md) to deploy a starter and publish
your first changes.

ZeroPress Static and Studio commit content to a GitHub repository; the
repository's build produces the static site. WordPress or Studio remains the
editing environment, separate from the static site's hosting.
[ZeroPress Edge](https://github.com/zeropress-app/zeropress-edge) optionally adds
comments, forms, and newsletters.
