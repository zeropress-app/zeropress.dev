# Themes And Tools

Start with your site's existing theme, then follow the guide for the change you
want to make:

| Guide | Use it to |
| --- | --- |
| [Customize a Theme](theme-authoring/index.md) | Edit a starter's theme, preview changes, and validate the build |
| [Templates and Data](theme-authoring/templates-and-data/index.md) | Render content and add reusable partials or page layouts |
| [Navigation and Collections](theme-authoring/navigation-and-collections/index.md) | Add menus, paginate posts, and define reading order |
| [Media and Integrations](theme-authoring/media-and-integrations/index.md) | Render images, style Markdown, and connect interactive features |

- [CLI Tools](cli/index.md): create themes, validate data, import, and build locally.
- [Static Search](static-search/index.md): connect theme search UI to native search or Pagefind.

To deploy your first site, follow [Getting Started](../getting-started/index.md).
For data fields and template contracts, use the [Reference](../reference/index.md).
