# ZeroPress Reference

Look up the contracts used by content generators, themes, and build tools.
For a working site, start with [Getting Started](../getting-started/index.md).

## Current Contracts

| Reference | Use it to |
| --- | --- |
| [Preview Data](preview-data/index.md) | Generate or validate the content supplied to a build |
| [Theme Runtime](theme-runtime/index.md) | Check manifests, template syntax, and rendering behavior |
| [Theme Package Limits](theme-runtime/package-limits/index.md) | Check package size, file, and path constraints |

Markdown source and site configuration are documented in the
[Build Pages reference](https://build-pages.zeropress.dev/reference/config/).
Machine-readable contracts are published at [schemas.zeropress.dev](https://schemas.zeropress.dev/).
